# AI Prose Review Library

中文小说文风审查库，来自 Roland 在 AI 协作修订中积累的作者手改、明确反馈和失败案例。关注重复解释、模板动作、人物声音和删改尺度，用上下文判断一句话是否有效。

公开版包含 **30 张方法卡**：24 张作者手改或明确评价卡、3 张代理返修卡、3 张迁移失败卡。H02、H03 中的候选曾被否定；R 系列只获得所在版本的整体反馈；F 系列是代理诊断，均保留原证据身份。

## 怎么用

1. 从 [CASES.md](CASES.md) 找与当前场景相近的问题，连同“保留边界”一起读。
2. 回到当前稿的前后文，说明重复了什么、删掉会失去什么。关键词只帮助检索。
3. 提出最小修改；事实、对白含义、伏笔和人物声音按作者授权处理。
4. 连读修改后的完整场景，核查因果、动作、情绪层次与段间衔接。失败候选不得当成正例复用。

我负责收集和校准作者反馈、区分证据身份、整理可复核案例，并将规则接入 AI 写作审稿流程。公开版保留方法卡和来源文档指纹，没有发布参考小说或修订稿全文。

## 检索

Python 3.10+，仅标准库：

```shell
python search_cases.py 对白
python search_cases.py H02
python search_cases.py --check
```

机器读取使用 `cases.json`。它保存问题、适用条件、保留边界、复核动作及来源指纹；哈希只标识来源版本，公开卡片本身不提供原稿全文核验。

本库不输出“AI 生成概率”，也不承诺绕过检测。句长、心理描写和特定词语不能单独判定文本质量或作者身份。配套 [三角色写作工作流](https://github.com/RolandWinston/ai-writing-workflow) 负责版本、分工与复核。
